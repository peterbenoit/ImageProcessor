# ImageProcessor Library Website

This is the official website for the [ImageProcessor](https://github.com/peterbenoit/ImageProcessor) JavaScript library, built with [Next.js](https://nextjs.org) and deployed on [Vercel](https://vercel.com).

## Features

-   Modern, dark-themed UI
-   Interactive image processing playground
-   Comprehensive documentation
-   Responsive design for all devices
-   SEO optimized

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

-   `src/app/`: Main application pages
-   `src/components/`: Reusable UI components
-   `src/lib/`: Utility functions and ImageProcessor integration
-   `public/`: Static assets including sample images

## Deploy on Vercel

Deploy your website using the [Vercel Platform](https://vercel.com/new) for the best experience with Next.js.
